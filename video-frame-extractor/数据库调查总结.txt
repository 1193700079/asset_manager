3. Prompt 相关字段
================================================================================

在 saved_frames 表中存储 prompt 的字段:

1. prompt (TEXT)
   - 内容: 生成的详细图片描述和生成指令
   - 数据量: 8,913 条记录 (37.26% 的总数)
   - 来源: AI 模型分析输出 (kimi, qwen 等)
   - 用途: 用于文生图 (Text-to-Image) 模型生成图片
   - 特点: 包含详细中文描述 + 英文指令，每条通常几 KB 到几十 KB

2. video_prompt (TEXT)
   - 内容: 针对视频生成的 prompt
   - 数据量: 仅 8 条记录
   - 用途: 文生视频 (Text-to-Video) 模型
   
3. i2v_prompt (TEXT)
   - 内容: 针对视频生成的 prompt (基于图像)
   - 数据量: 仅 8 条记录
   - 用途: 图生视频 (Image-to-Video) 模型

相关补充字段:
  - description: 简短文本描述
  - model_id: 生成该 prompt 的 AI 模型 (qwen, kimi, etc.)
  - format: 标注类型 (image_annotation 有 prompt, image_prescreen 没有)
  - status: 记录状态 (labeled, skipped, etc.)
  - feedback: 人工反馈 (good, bad, 等)
  - dimensions: 14 维结构化标注 (JSON 格式)

5. 如何访问 Prompt 数据
================================================================================

方法 1: Python + psycopg2 (推荐)

  import psycopg2
  from psycopg2.extras import RealDictCursor
  
  conn = psycopg2.connect(
      host="127.0.0.1",
      port=5432,
      database="video_frames",
      user="video_frames",
      password="video_frames_pwd"
  )
  
  with conn.cursor(cursor_factory=RealDictCursor) as cur:
      cur.execute("""
          SELECT id, prompt, model_id, created_at
          FROM saved_frames
          WHERE prompt IS NOT NULL
          ORDER BY created_at DESC
          LIMIT 10
      """)
      rows = cur.fetchall()
      for row in rows:
          print(row)
  
  conn.close()

方法 2: SQL 查询

  # 获取所有 prompt
  SELECT id, video_path, prompt, model_id, created_at
  FROM saved_frames
  WHERE prompt IS NOT NULL
  ORDER BY created_at DESC
  LIMIT 100;
  
  # 统计 prompt 数据
  SELECT COUNT(*) as total, COUNT(CASE WHEN prompt IS NOT NULL THEN 1 END) as with_prompt
  FROM saved_frames;

方法 3: 命令行 psql

  PGPASSWORD="video_frames_pwd" psql -h 127.0.0.1 -U video_frames -d video_frames \
    -c "SELECT id, prompt FROM saved_frames WHERE prompt IS NOT NULL LIMIT 5;"

7. 关键发现
================================================================================

1. Prompt 存储位置: saved_frames.prompt 字段

2. Prompt 数据特性:
   - 数据量: 约 8,913 条记录
   - 内容: 中文描述 + 英文指令混合
   - 大小: 通常几 KB 到几十 KB
   - 来源: AI 模型自动生成 (主要是 qwen 和 kimi 模型)

3. 生成模型:
   - 主要模型: qwen (1,636), qwen-3.5 (1,630), qwen-3.7-plus (1,607)
   - 其他模型: kimi (1,602), kimi-k2.5 (1,571), kimi-k2.6 (7), qwen3.6-plus (10)
   - 每条记录记录了 model_id，可以追溯是哪个模型生成的

4. 相关数据:
   - image_annotation: 包含 prompt 的标注图片 (8,841 条)
   - image_prescreen: 预筛选结果，无 prompt (14,814 条)
   - 其他格式: jpeg, video, skip 等

5. 关键表关系:
   - saved_frames.id <-> prompt_usage.frame_id (外键关系)
   - 删除 saved_frames 记录会级联删除对应的 prompt_usage 记录
