================================================================================
使用示例
================================================================================

Python 中加载和使用:

    import json, random
    
    # 加载素材库
    with open('occupations_realistic.json') as f:
        occupations = json.load(f)
    
    # 随机选择职业
    all_jobs = []
    for jobs in occupations.values():
        all_jobs.extend(jobs)
    
    job = random.choice(all_jobs)
    print(f"职业: {job['title']}")
    print(f"描述: {job['description']}")

使用场景
================================================================================

真人角色 (girlfriend/boyfriend):

生成流程:
1. 从 names_by_ethnicity.json 选择种族和名字
2. 从 occupations_realistic.json 选择职业
3. 从 hobbies.json 选择 2-3 个爱好
4. 从 personalities.json (realistic) 选择性格
5. 从 body_types.json 选择体型
6. 从 relationship_status.json 选择关系状态

示例输出:
  名字: Emma Johnson
  种族: Caucasian
  职业: Software Engineer
  爱好: Photography, Hiking, Reading
  性格: Creative, Adventurous, Intelligent
  体型: Athletic
  关系状态: Single

────────────────────────────────────────────────────────────────

动漫角色 (anime_female/anime_male):

生成流程:
1. 从 names_anime.json 选择名字 (名 + 姓)
2. 从 occupations_anime.json 选择身份/职业
3. 从 hobbies.json 选择爱好
4. 从 personalities.json (anime_types) 选择性格类型
5. 从 body_types.json 选择体型

示例输出:
  名字: Sakura Tanaka
  身份: Magical Girl
  爱好: Anime watching, Gaming
  性格: Deredere (Innocent, overtly affectionate)
  体型: Petite
